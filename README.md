# CampusNotes

A lightweight student notes workspace for organizing course notes by subject. This repository is used for IILM University VCS Assignment-2 (CSE25303).

## Student
- Enrollment: 2581403
- Course: CSE25303 — Version Control System

## Project structure
- `src/` — application source
- `tests/` — basic tests
- `.githooks/` — shared Git hook scripts
- `docs/` — assignment notes and Git workflow evidence

## Run
Open `index.html` in a browser. No build tools or external dependencies are required.

## Git hooks
Configure the tracked hooks with `git config core.hooksPath .githooks` and make the scripts executable (`chmod +x .githooks/*`).
